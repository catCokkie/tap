# 玩家存档迁移与保护策略（v0.1）

> 日期：2026-02-18  
> 执行者：Codex

## 1. 目标

- 在版本迭代中保护玩家存档不丢失。
- 支持旧版存档自动迁移到当前版本。
- 存档损坏时可自动回退到可用备份。

## 2. 技术策略

### 2.1 版本化存档封装

- 存档结构采用 `SaveEnvelope`：
  - `schemaVersion`
  - `gameVersion`
  - `savedAt`
  - `stateHash`
  - `state`
- 当前 schema：`v2`

### 2.2 兼容加载与迁移

- 读取时先判断是否为 envelope：
  - 是：按 `schemaVersion` 进入迁移流程
  - 否：按 legacy `v1` 裸 `GameState` 处理并迁移
- 迁移入口保留为逐版本链式处理（`v1 -> v2 -> ...`），避免跳跃式不可控改动。

### 2.3 完整性校验

- 保存时对 `state` 计算 SHA-256，写入 `stateHash`。
- 加载时校验 hash，失败视为损坏，触发备份恢复。

### 2.4 备份与回滚

- 每次覆盖主存档前：
  - 刷新 `user://save_backup.json`（最近备份）
  - 生成带时间戳的历史备份到 `user://save_backups/`
- 保留最近 `12` 份历史备份，自动清理更旧文件。
- 主存档损坏时按顺序恢复：
  - 最近备份
  - 历史备份（从新到旧）

## 3. 玩家侧收益

- 版本更新后旧档可自动升级，无需手动清档。
- 遇到异常写盘或意外中断时可自动回退。
- 存档异常有可追溯备份文件，便于定位问题。

## 4. 后续计划（v0.2）

- 增加“手动导出/导入存档”入口。
- 增加“迁移日志”可视化（显示从哪个 schema 迁移）。
- 为迁移逻辑补单元测试（每个 schema 对应一组样本存档）。
