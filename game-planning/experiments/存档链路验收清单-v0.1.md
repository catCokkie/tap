# 《仙途漫记》存档链路验收清单 v0.1

> 执行者：Codex

## 0. 测试前准备

- [ ] 当前版本可正常启动
- [ ] `dotnet test tap.sln` 通过
- [ ] 记录当前测试时间与测试人

记录：
- 测试时间：`____-__-__ __:__`
- 测试人：`________`

---

## 1. 基础导出验证

- [ ] 进入游戏并产生可识别进度（如：境界、修为、背包数量变化）
- [ ] 点击“导出存档（玩家）”
- [ ] 确认导出文件存在：`user://exports/save_export_latest.json`
- [ ] 文件大小 > 0，且可打开为 JSON

验收：
- [ ] 导出成功提示文案正常
- [ ] 无报错弹窗/异常日志

---

## 2. 导入覆盖验证（正常文件）

- [ ] 保持导出文件不变，继续游玩 1~2 分钟制造“新进度”
- [ ] 点击“导入存档（玩家）”导入刚才的导出文件
- [ ] 重启游戏

对比项（导入后应回到导出时状态）：
- [ ] 境界/小境界一致
- [ ] 修炼进度一致（允许微小显示误差）
- [ ] 背包关键物品数量一致（草药/丹药/材料）
- [ ] 系统进度一致（灵药/灵宠/炼丹/炼器）

---

## 3. 损坏文件导入验证

- [ ] 复制导出文件为 `save_import.json`
- [ ] 手工破坏 JSON（如删一个括号）
- [ ] 执行导入

验收：
- [ ] 导入失败提示清晰
- [ ] 当前有效存档未被覆盖
- [ ] 重启后仍可正常读取原有存档

---

## 4. 备份回退验证

- [ ] 人工破坏主存档 `user://save.json`
- [ ] 保留一份有效备份（latest 或历史）
- [ ] 启动游戏触发恢复

验收：
- [ ] 能自动恢复到有效备份
- [ ] 恢复后可继续正常游玩与保存
- [ ] 日志中可看到恢复来源（latest_backup 或历史备份文件名）
