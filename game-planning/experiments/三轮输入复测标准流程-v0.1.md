# 三轮输入复测标准流程（v0.1）

> 日期：2026-02-18  
> 执行者：Codex  
> 目标：用固定步骤完成“低/中/高”三轮复测，并回填实验记录与看板数据。

---

## 1. 复测前准备（2分钟）

- [ ] 使用同一存档、同一境界进行测试
- [ ] 固定分配策略（建议自动分配）
- [ ] 关闭调试注入（不手动加修为/资源池）
- [ ] 打开游戏内：`测试菜单 -> 输入统计（三轮实验）`
- [ ] 清空旧记录（点击“重置三轮”）

---

## 2. 三轮测试步骤（每轮5分钟）

### 第1轮：低强度办公

- [ ] 选择“第1轮（低强度办公）”
- [ ] 点击“开始本轮”
- [ ] 保持轻度打字、偶尔点击、低频滚轮
- [ ] 5分钟后点击“结束本轮”（或自动结束）

### 第2轮：中强度使用

- [ ] 选择“第2轮（中强度使用）”
- [ ] 点击“开始本轮”
- [ ] 保持持续输入，包含较多键鼠切换
- [ ] 5分钟后点击“结束本轮”（或自动结束）

### 第3轮：高强度游戏/码字

- [ ] 选择“第3轮（高强度游戏/码字）”
- [ ] 点击“开始本轮”
- [ ] 保持高频键鼠输入、连续操作
- [ ] 5分钟后点击“结束本轮”（或自动结束）

---

## 3. 导出与回填（3分钟）

- [ ] 在输入统计页面点击“导出结果”
- [ ] 确认导出文件已生成：
  - `game-planning/experiments/三轮输入强度实验记录-自动导出-latest.md`
  - `game-planning/experiments/三轮输入强度实验记录-自动导出-latest.csv`
- [ ] 将关键结果回填到：
  - `game-planning/experiments/三轮输入强度实验记录-v0.1.md`
  - `game-planning/MetricsDashboard-v0.1.md`（基线表）

---

## 4. 判读规则（简版）

- `effective_input_per_min` 三档差异过小（<20%）  
  说明递减过重，放宽软上限段。
- 高档/中档倍率过高（>1.8）  
  说明递减偏弱，收紧超软上限段。
- 低强度 `main_gain_per_min` 过低  
  提高基础转化率或提高主修炼默认分配。

---

## 5. 调参纪律

- 每次只改 `1~2` 个参数
- 每次调参后至少复测一次三轮
- 变更要写入 `MetricsDashboard-v0.1.md` 的参数记录区
