## A. 开测前（30秒）

- [ ] 同一存档 / 同一境界 / 同一分配策略（建议自动）
- [ ] 关闭调试注入
- [ ] 打开：`测试菜单 -> 输入统计（三轮实验）`
- [ ] 点击：`重置三轮`

## B. 三轮操作（每轮5分钟）

1. 第1轮 低强度办公：开始本轮 -> 5分钟 -> 结束本轮  
2. 第2轮 中强度使用：开始本轮 -> 5分钟 -> 结束本轮  
3. 第3轮 高强度游戏/码字：开始本轮 -> 5分钟 -> 结束本轮

## D. 快速判读阈值

- 三档 `effective_input_per_min` 差异 < 20%：递减过重（放宽软上限）
- 高档/中档倍率 > 1.8：递减过弱（收紧超软上限）
- 低强度 `main_gain_per_min` 过低：提高基础转化率或主修炼分配

## E. 调参纪律

- 每次只改 1~2 个参数
- 每次改完至少复测一轮
- 参数变更同步记录到 `MetricsDashboard-v0.1.md`
