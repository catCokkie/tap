# 玩家存档导入导出说明（v0.1）

> 日期：2026-02-18  
> 执行者：Codex

## 1. 功能入口

- 游戏内：`游戏菜单`
- 按钮：
  - `导出存档（玩家）`
  - `导入存档（玩家）`

## 2. 默认路径

- 导出文件：
  - `user://exports/save_export_latest.json`
- 导入文件：
  - `user://imports/save_import.json`

说明：`user://` 为 Godot 的用户数据目录，实际绝对路径会因系统和项目而异。

## 3. 导出流程

1. 点击 `导出存档（玩家）`
2. 系统会把当前主存档复制到导出路径
3. 导出成功后会在日志显示导出结果

## 4. 导入流程

1. 将要导入的存档放到：
   - `user://imports/save_import.json`
2. 点击 `导入存档（玩家）`
3. 系统会执行：
   - 存档结构解析与版本迁移
   - 完整性校验
   - 覆盖主存档前自动备份当前存档
4. 导入成功后自动重载场景生效

## 5. 安全与回滚

- 导入覆盖前会自动保留当前存档备份。
- 导入文件损坏或不合法会拒绝导入，不会覆盖当前可用存档。
- 详细策略见：
  - `game-planning/玩家存档迁移与保护策略-v0.1.md`
