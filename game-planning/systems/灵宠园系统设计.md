# 灵宠园系统设计

> 日期：2026-02-16  
> 执行者：Codex

## 1. 定位

- 解锁阶段：金丹期
- 系统职责：通过派遣机制提供补充材料与稀有词条
- 体验目标：低频设置，高价值回收

## 2. 输入与输出

- 输入：`SpiritPetPool`
- 输出：灵宠回收奖励（材料、稀有种子、词条碎片）
- 联动：灵药园稀有种子来源、炼器坊词条来源

## 3. 核心循环

1. 分配修行值进入灵宠池。
2. 触发派遣任务并进入倒计时。
3. 派遣完成自动结算奖励。
4. 玩家只需调整派遣偏好（稳健/收益/稀有）。

## 4. 规则（v1）

- 初始派遣队列：1
- 派遣时长：10~30分钟（随阶段缩短）
- 奖励构成：
  - 常规材料（高概率）
  - 稀有材料（中概率）
  - 词条碎片（低概率）

## 5. 风险与回报

- 稳健派遣：收益稳定，稀有率低
- 冒险派遣：收益波动大，稀有率高

## 6. 与转世系统关系

- 转世可提升：
  - 派遣速度
  - 稀有奖励权重
  - 队列上限

## 7. 验收标准

- 金丹后可稳定触发自动派遣循环。
- 玩家不手动点收也能正常回收奖励。
- 派遣策略切换后收益结构可见差异。
