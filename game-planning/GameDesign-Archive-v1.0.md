## 1. 项目概述

### 1.1 游戏基本信息

| 字段 | 内容 |
|------|------|
| **中文名** | 仙途漫记 |
| **英文名** | Immortal Idle / Cultivation Clicker |
| **核心类型** | 文字放置 + 观察收集 + 点击放置 |
| **主题** | 修仙/东方玄幻 |
| **平台** | Windows桌面（Godot导出支持跨平台） |
| **引擎** | Godot 4.x |
| **语言** | C# |
| **美术** | DEMO: 文字+少量像素画 → MVP: 文字+像素画 |
| **预期时长** | 首次通关5-10h，100%完成30-50h |

### 1.2 核心概念

《仙途漫记》是一款**桌面文字放置修仙游戏**。玩家扮演一位初入仙途的修行者（第108代外门弟子，资质平平、债务惊人），通过挂机修炼、收集奇遇、记录见闻，逐步从凡人成长为一代仙尊。

**核心体验**:
- 打开游戏窗口，看着角色自动修炼
- 阅读修炼日志，记录奇遇事件
- 收集功法、法宝、灵宠
- 规划修炼方向，突破境界

**一句话卖点**:  
> "你在打工摸鱼，它在桌面修仙；你点一下，它就给你整一出离谱奇遇。"

### 1.3 游戏定位

| 维度 | 定位 |
|------|------|
| **类型** | 文字放置 + 观察收集 |
| **核心体验** | 陪伴感、收集欲、成长成就感 |
| **单次游玩** | 随时打开，随时关闭，无压力 |
| **交互时长** | 10秒到2分钟 |
| **关键词** | 低打扰、持续陪伴、随机整活、长期成长 |

### 1.4 目标受众

- 喜欢修仙/玄幻文化的玩家
- 喜欢放置类游戏、不喜欢操作的玩家
- 工作/学习时想要桌面陪伴的玩家
- 喜欢收集和阅读日志文本的玩家

## 2. 核心玩法设计

### 2.1 核心游戏循环（4层嵌套）

```
第1层（秒级）：点击反馈循环
  玩家点击 → 获得1修为 → 数字跳动 → 听到音效
  心理驱动：即时满足感

第2层（分钟级）：投资决策循环
  累积修为 → 选择是否购买功法/升级
  → 新的被动收益激活 → 产出速率提升
  心理驱动：成就感、优化感

第3层（小时级）：成就解锁循环
  完成任务 → 解锁新伙伴/功法
  → 新的玩法机制 → 重新刺激探索欲
  心理驱动：探索感、收集欲

第4层（长期）：超越重置循环
  达到分神期 → 触发天破劫 → 飞升重置
  → 游戏难度重新开始但玩家更强
  → 快速推进到新内容 → 刺激前期受挫感补偿
  心理驱动：长期目标、投资回报
```

### 2.2 修仙主题融合（6维度）

| 维度 | 游戏元素 | 融合方式 |
|------|----------|----------|
| **境界修行** | 7层突破系统 | 奠基期→分神期渐进成长 |
| **功法修炼** | 功法系统（15-20种） | 选择性投资+组合策略 |
| **伙伴情感** | 伙伴系统（12-15个） | 收集、培养、配对、故事 |
| **资源采集** | 多层资源链 | 修为→灵石→灵药→丹药 |
| **秘境冒险** | 事件系统 | 副本、任务、限定活动 |
| **飞升成仙** | 超越重置 | 长期目标、永久进度 |

### 2.3 点击放置核心机制

| 机制 | 说明 |
|------|------|
| **点击源** | 基础操作，1 CP/次，可升级强度 |
| **自动化** | 购买功法替代手动，5x→1000x+ |
| **升级系统** | 成本指数增长：1.15^倍率，收益线性增长：1.05^倍率 |
| **超越重置** | 完整重置获得永久加成，回到早期但加速推进 |
| **离线收益** | 断线加速（8小时上限），100%收益 |

## 3. 系统设计详解

### 3.1 修炼系统（放置成长）

#### 自动修炼
- 角色持续自动修炼，产生**修为**
- 修为达到阈值后可**突破境界**
- 修炼速度受功法、灵根、环境等因素影响

#### 境界体系（七境）

| 序号 | 境界名 | 基础突破需求 | 新解锁 | 修为跃升 |
|------|--------|--------------|--------|----------|
| 1 | 奠基期 | 100 | 打坐、功法 | - |
| 2 | 筑基期 | 500 | 新伙伴、新功法 | ×1.5 |
| 3 | 灵旺期 | 2000 | 灵根系统 | ×2.0 |
| 4 | 金丹期 | 10000 | 丹药炼制 | ×3.0 |
| 5 | 元婴期 | 50000 | 秘境副本 | ×5.0 |
| 6 | 度劫期 | 200000 | 天劫系统 | ×10.0 |
| 7 | 分神期 | 1000000 | 多元化身 | ×20.0 |

注：当前实现为每个大境界包含四个小阶段（初期/中期/后期/圆满），实际单次突破需求 = 基础需求 × (当前小阶段序号 + 1)。

#### 修炼速度
- 基础修炼速度: 1修为/秒
- 功法加成: +10%~+100%
- 洞府加成: +20%~+50%
- 境界瓶颈: 后期境界修炼速度-50%

### 3.2 奇遇系统（观察收集）

#### 奇遇触发
- 修炼过程中随机触发奇遇事件
- 奇遇类型：发现宝物、遭遇敌人、遇见仙人、领悟功法等
- 奇遇自动处理，结果写入**修仙日志**

#### 奇遇事件类型

| 类型 | 描述 | 可能结果 |
|------|------|----------|
| **洞府奇遇** | 发现前人洞府 | 获得功法、法宝、材料 |
| **战斗遭遇** | 遭遇妖兽/魔修 | 战胜获得战利品/战败受伤 |
| **仙人指点** | 偶遇高人 | 获得指点、功法、道具 |
| **天地异象** | 感悟天道 | 修为大涨、领悟神通 |
| **灵宠结缘** | 遇到灵兽 | 收服/战斗/错过 |
| **坊市淘宝** | 发现坊市 | 交易、捡漏 |

#### 日志系统
- 所有修炼过程和奇遇以文字形式记录
- 日志可分类查看：全部、修炼、奇遇、突破、收获
- 支持收藏重要日志
- 支持导出修仙回忆录

### 3.3 功法系统

#### 功法列表（15-20种）

| 功法名称 | 产出速率 | 解锁境界 | 特色 |
|----------|----------|----------|------|
| 静心经 | 5 CP/s | 奠基期 | 基础，无加成 |
| 九阳真经 | 25 CP/s | 奠基期中期 | 火系，单体强力 |
| 天寒诀 | 25 CP/s | 奠基期中期 | 冰系，冷却加成 |
| 六阴真诀 | 50 CP/s | 筑基期 | 阴系，暗弱克星 |
| 青木心法 | 75 CP/s | 筑基期 | 木系，生命回复 |
| 长生诀 | 100 CP/s | 金丹期 | 生命流，综合增益 |
| 混沌真经 | 500 CP/s | 元婴期 | 混沌系，全能 |
| 渡劫之心 | 5000 CP/s | 度劫期 | 雷系，爆发性 |
| 永恒法则 | 50000 CP/s | 分神期 | 时空系，最强 |

#### 功法升级机制
```
等级范围：Lv.1 - Lv.100
成本计算：Cost(Lv) = BasePrice × (1.15 ^ (Lv - 1))
收益计算：Benefit(Lv) = BaseOutput × (1.05 ^ (Lv - 1))
```

### 3.4 伙伴系统

#### 伙伴角色列表（12-15个）

| 伙伴名 | 属性 | 特技 | 获得方式 |
|--------|------|------|----------|
| 云落 | 水系 | 冷却加速-5% | 奠基期任务 |
| 青茶 | 木系 | 修为+5% | 筑基期任务 |
| 朱雀 | 火系 | 点击强化×1.5 | 金丹期抽卡 |
| 青龙 | 木系 | 功法产出+10% | 金丹期抽卡 |
| 白虎 | 金系 | 防守加强 | 元婴期任务 |
| 玄武 | 水系 | 回血+20% | 元婴期任务 |
| 西门吹雪 | 特殊 | 剑气·一品 | 度劫期抽卡 |

#### 伙伴培养
- 伙伴等级：Lv.1 - Lv.50
- 升级资源：心愿值（伙伴核心升级货币）
- Lv.10: 解锁伙伴剧情第一幕
- Lv.25: 解锁伙伴秘技
- Lv.50: 伙伴转化（化身为永久BUFF）

### 3.5 资源系统

| 资源 | 获取方式 | 用途 |
|------|----------|------|
| **修为** | 自动修炼 | 突破境界 |
| **灵石** | 奇遇/洞府产出 | 交易、加速修炼 |
| **材料** | 奇遇/采集 | 炼器、炼丹 |
| **功法点** | 领悟功法 | 学习新功法 |
| **心境** | 自动恢复 | 影响奇遇成功率 |

### 3.6 超越系统（飞升重置）

#### 触发条件
- 达到分神期后，遇到第一次"天破劫"
- 必然的剧情演出，飞升重置

#### 重置收益
```
基础加成：
- 起始修为 +10% × (飞升次数)
- 所有功法产出 +5% × (飞升次数)
- 打坐点击强度 +1 × (飞升次数)

进度加成：
- 伙伴关系保留（等级重置为1，心愿值保留50%）
- 已解锁功法仍然可用（等级重置）
- 已完成任务的永久奖励保留

新特性解锁：
- 第1次飞升后：可配置多个伙伴组合
- 第2次飞升后：解锁"修为风暴"
- 第3次飞升后：解锁"轮回转世"
```

### 3.7 图鉴收集系统

- **功法图鉴**: 记录已获得的修炼功法
- **法宝图鉴**: 记录已获得的法宝
- **灵宠图鉴**: 记录已收服的灵宠
- **见闻图鉴**: 记录特殊奇遇事件
- **人物图鉴**: 记录遇到的NPC
