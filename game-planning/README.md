## 🎮 游戏概览

### 核心体验
桌面文字修仙养成游戏，玩家通过日常键盘/鼠标输入推进修行，逐步解锁自动系统与转世继承成长。

### 核心循环
```
输入积累 → 转化修行值 → 自动系统产出 → 突破境界 → 转世继承 → 新周目提速
```

### 关键系统
- **输入系统**: 键鼠输入转化修行值
- **修炼系统**: 在线自动增长修为
- **境界系统**: 7层突破（奠基→筑基→灵旺→金丹→元婴→度劫→分神）
- **阶段系统**: 灵药园/灵宠园/炼丹/炼器逐步解锁
- **转世系统**: 局外资源继承与周目加速
